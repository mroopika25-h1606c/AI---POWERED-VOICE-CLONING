HOW TO USE (For Team Members)

MEMBER 2 (AI/ML - You):
─────────────────────
1. Download full ASVspoof 2019 LA dataset:
   python download_dataset.py  # Follow instructions

2. Organize downloaded dataset:
   python organize_dataset.py --dataset dataset/LA

3. Train on full dataset:
   python train.py --dataset dataset/LA --epochs 100 --device cuda --batch-size 32
   # Takes ~4-6 hours on GPU, produces ~95%+ accuracy

4. Evaluate model:
   python train.py --dataset dataset/LA --epochs 0  # Run validation/test only


MEMBER 3 (Backend/FastAPI):
───────────────────────────
1. Integrate inference into FastAPI:
   from inference.predict import VoiceSpoofingDetector
   
   # In your FastAPI app:
   detector = VoiceSpoofingDetector(model_path="checkpoints/best.pth")
   result = detector.predict("audio.wav")

2. Or use the complete FastAPI template:
   python api.py  # Starts server on http://localhost:8000
   # Visit http://localhost:8000/docs for interactive API docs

3. API Endpoint:
   POST http://localhost:8000/predict
   Content-Type: multipart/form-data
   Body: Audio file (WAV, FLAC, MP3)
   Response: JSON with prediction + confidence
