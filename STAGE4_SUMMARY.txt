==============================================================================
MODEL ARCHITECTURE DETAILS
==============================================================================

Input → Conv Frontend → Residual Blocks → Self-Attention → Classification

Convolutional Frontend:
  Conv2D(1, 32, 3×3) → BN → ReLU → MaxPool(2×2)
  Conv2D(32, 64, 3×3) → BN → ReLU → MaxPool(2×2)
  Conv2D(64, 128, 3×3) → BN → ReLU → MaxPool(2×2)

Residual Blocks (×2):
  Conv2D(128, 128, 3×3) → BN → ReLU → Dropout
  Conv2D(128, 128, 3×3) → BN → ReLU → Dropout + Skip Connection

Self-Attention Layer:
  MultiHeadAttention(embed_dim=128, num_heads=8)
  Learns temporal dependencies in spectrograms

Classification Head:
  Linear(128, 256) → ReLU → Dropout → Linear(256, 2)
  Output: Logits for [Real, Fake]
